## Sobre o projeto

Projeto desenvolvido como parte do desafio prático da DIO, com o objetivo de consolidar conhecimentos sobre gerenciamento de instâncias Amazon EC2 na AWS.

## Objetivos

- Compreender os conceitos fundamentais do Amazon EC2.
- Conhecer os estados de uma instância.
- Entender as operações Start, Stop, Reboot e Terminate.
- Estudar mecanismos de segurança.
- Compreender o controle de custos na nuvem.
- Desenvolver documentação técnica utilizando GitHub.
